## Validation

- Generated snapshot: all 13 files match; all referenced source bytes match the published revision.
- Regression tests: 9 pass at the time of this review (10 today, after the per-model link-id guard), covering graph references, Sankey cycles, frame/barrier validity, source bounds, enum locations, schedule extraction, and static path resolution.
- TypeScript and full application Biome lint pass.
- Production build exports 21 pages with bundled local fonts.
- Exported HTML: 319 internal links checked, no missing pages/fragments or duplicate IDs.
- Browser checks: 11 interaction scenarios pass, covering model navigation, graph search/inspection, URL state and malformed-value fallback, KV replay/keyboard range/model reset, filters and empty states, timeline selection, mobile navigation, reduced-motion layout, themes, and 404 behavior.
- Accessibility and hydration: all 18 public routes return HTTP 200 with no axe WCAG 2 A/AA or 2.1 AA violations in the tested light/dark initial page states, no page/hydration errors, and no horizontal overflow at 390px. Screenshot review additionally checked SVG labels that axe does not evaluate. A separate rendered-style check verifies 987 themed SVG labels per theme across six representative pages (including duplicate inline/sticky figures). These automated checks are not a complete WCAG conformance audit.

The local build used Node 25.2.1 and the workspace-managed pnpm 11.10.0. The workspace recommends Node 24.16.0; use the pinned versions for team/CI reproduction. Validation set `pnpm_config_verify_deps_before_run=false` to reuse the installed workspace dependencies without pnpm attempting a reinstall; dependencies and the lockfile were not changed. Browser validation used installed Chromium through Playwright 1.61.0 and axe-core 4.12.1; mobile checks are viewport emulation, not physical-device Safari tests. Turbopack and local preview/browser workers required execution outside the filesystem sandbox because its local-port restrictions prevented CSS processing and browser startup. The application itself needed no inference server, model weights, API keys, or font downloads.

## Scope and sharing

The app is an educational companion with selected representative paths. It is not a live runtime trace, exhaustive model compatibility catalog, or new numerical/performance qualification. Separate Qwen3 text-generation/text-reranker walkthroughs and GLiNER classification/relation diagrams remain outside this tour; the compatibility link makes the broader serving policy available.

No inference kernels or model weights changed, and no model workloads or hardware benchmarks were run. Historical performance values remain historical. For local review, run `pnpm preview` after building; for sharing, publish the generated `out/` directory with the static routing behavior documented in `README.md`. This branch already tracks the export directory, so its generated output is refreshed locally along with source changes.
