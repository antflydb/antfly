# antfly-cli

Python package for installing the native Antfly CLI.

Supported Python versions: 3.11 through 3.14.

CLI PyPI publication is currently paused. Install the current CLI through
`npm install -g @antfly/cli`, Homebrew, or the native release archives.

This package is separate from `antfly-sdk`, which contains the Python SDK.
Historical release wheels include the `antfly` executable, Antfarm dashboard assets, and
the Antfly C ABI header/library for the target platform.
