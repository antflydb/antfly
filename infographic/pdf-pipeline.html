Stages 5–7 · Windows & inference · 3 / 4

Render the next window
while the model reads this one.

Rendering never races ahead of inference across the whole document. A double-buffered loop overlaps CPU rendering of window N+1 with GPU inference on window N — and the second window must win its own composite memory lease first.

Deadlock-free resource order

1

Document extraction working-set lease
parse, plan, coordinator state — all budgeted

2

Render-window lease
scratch may be partially granted; output peak required in full

3

Inference queue units
only after the window is ready — never held while waiting on renderers

Released in reverse. If inference is saturated, rendering simply stops at the admitted window.

Two-level scheduling

Antfly owns the logical queue. Requests are partitioned by execution compatibility before media is materialized: interleaved A,B,A,B become A,A + B,B. Compatibility = model generation, task, provider scope, prompt/schema, input representation and resource class — not just model name.

The inference node owns physical execution. It fuses eligible work across multiple Antfly clients, admits against the loaded model and device, and dispatches through the task's executor. Borrowed page attachments carry item/source/page identity, so pages from different documents can share one native batch.

Stage 8 · Correctness & failure · 4 / 4

OCR has to earn
its place on the page.

Results are joined by page_number, never completion order. A page can't be persisted as OCRed until its output passes validation and beats the embedded text on quality.

Selection rules

  • Empty embedded text can't beat meaningful OCR.
  • Empty, punctuation-only and prompt-echo OCR is always rejected.
  • A short transcription can't replace substantial embedded content.
  • Both pass quality? Keep the embedded text — "longer" isn't "better".
  • Quality sampling uses bounded, deterministically offset intervals: a spaced heading can't condemn good body text; a clean prefix can't hide later corruption.
  • Selected-but-weak OCR is flagged ocr_selected_low_quality.

Three failure classes

Per-page permanent

Malformed content stream, over-limit page, trivial OCR. Recorded; valid siblings continue.

Batch / provider

Count mismatch, unsupported shape. Only that microbatch retries serially — with the reason recorded.

Systemic retryable

Capacity, shutdown, memory pressure. Cancel and join every render task, then hand back to the durable enrichment worker.

Page-image identity antfly-pdf-page-embedding-v4 hashes the source digest & page, DPI & resolution policy, pixel/dimension caps, renderer ceilings, decoder limits, transport, and resolved image transform. Change any of them and staged + published vectors are invalidated. One missing vector fails the whole document attempt — partial responses can't silently shrink what's searchable.
