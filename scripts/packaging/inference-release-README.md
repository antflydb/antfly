# Antfly Inference (legacy archive)

This legacy split-product Apache-2.0 archive contains the standalone `antfly-inference` CLI.
Run `./antfly-inference --help` for commands including `run`, `embed`,
`generate`, `chat`, `list`, and `pull`. It can run inference without an
Antfly database or `libantfly`.

The product license is in `LICENSE`. Third-party licenses and notices are in
`LICENSES/third-party/` and `THIRD_PARTY_NOTICES.md`.
