# SDKs

Antfly provides type-safe client libraries for Go, TypeScript, Python, and Rust. The Go, TypeScript, and Python SDKs are hand-written clients over code generated from the [OpenAPI specification](/docs/api); the Rust SDK is generated from it end to end.

| Language | Package | Registry | Source |
|----------|---------|----------|--------|
| Go | `github.com/antflydb/antfly/go/pkg/sdk` | [pkg.go.dev](https://pkg.go.dev/github.com/antflydb/antfly/go/pkg/sdk) | [GitHub](https://github.com/antflydb/antfly/tree/main/go/pkg/sdk) |
| TypeScript | `@antfly/sdk` | [npm](https://www.npmjs.com/package/@antfly/sdk) | [GitHub](https://github.com/antflydb/antfly/tree/main/ts/packages/sdk) |
| Python | `antfly-sdk` | [PyPI](https://pypi.org/project/antfly-sdk/) | [GitHub](https://github.com/antflydb/antfly/tree/main/py/packages/sdk) |
| Rust | `antfly-sdk` | Not yet published; use a git dependency | [GitHub](https://github.com/antflydb/antfly/tree/main/rs/crates/sdk) |

## Embedded Lite Binding

Antfly Lite embeds Antfly directly in an application process with a live
`.aflite` database file. The first Lite binding above Zig and C is Go:

```bash
go get github.com/antflydb/antfly/go/pkg/antflylite
```

The Lite binding is separate from the network SDK. Use
`github.com/antflydb/antfly/go/pkg/sdk` for a running Antfly service and
`github.com/antflydb/antfly/go/pkg/antflylite` for embedded local databases.

See the [Antfly Lite guide](/docs/guides/lite) for CLI and Go embedded
examples, plus backup, restore, and promotion between Lite and a running
instance.

## Authentication

All three authentication methods are supported across SDKs: basic auth, API key, and token.

### Basic Auth

<CodeTabs persistKey="sdk-lang" samples={[
  {
    language: "Go",
    code: `import (\n\tantfly "github.com/antflydb/antfly/go/pkg/sdk"\n\t"github.com/antflydb/antfly/go/pkg/sdk/oapi"\n)\n\nclient, err := antfly.NewAntflyClientWithOptions(\n\t"http://127.0.0.1:8080",\n\toapi.WithRequestEditorFn(antfly.WithBasicAuth("admin", "password")),\n)`
  },
  {
    language: "TypeScript",
    code: `import { AntflyClient } from '@antfly/sdk';\n\nconst client = new AntflyClient({\n  baseUrl: 'http://127.0.0.1:8080',\n  auth: {\n    username: 'admin',\n    password: 'password',\n  },\n});`
  },
  {
    language: "Python",
    code: `from antfly import AntflyClient\n\nclient = AntflyClient(\n    base_url='http://127.0.0.1:8080',\n    username='admin',\n    password='password',\n)`
  },
  {
    language: "Rust",
    code: `// Cargo.toml also needs: base64 = "0.22"\nuse antfly_sdk::new_client;\nuse base64::Engine as _;\nuse reqwest::header::{AUTHORIZATION, HeaderMap, HeaderValue};\n\nlet encoded = base64::engine::general_purpose::STANDARD.encode("admin:password");\nlet mut headers = HeaderMap::new();\nheaders.insert(\n    AUTHORIZATION,\n    HeaderValue::from_str(&format!("Basic {encoded}"))?,\n);\n\nlet client = new_client(\n    "http://127.0.0.1:8080",\n    reqwest::Client::builder().default_headers(headers).build()?,\n);`
  }
]} />

## Quick Start

### Insert Documents

<CodeTabs persistKey="sdk-lang" samples={[
  {
    language: "Go",
    code: `import (\n\t"context"\n\t"log"\n\n\tantfly "github.com/antflydb/antfly/go/pkg/sdk"\n\t"github.com/antflydb/antfly/go/pkg/sdk/oapi"\n)\n\nctx := context.Background()\nclient, err := antfly.NewAntflyClientWithOptions(\n\t"http://127.0.0.1:8080",\n\toapi.WithRequestEditorFn(antfly.WithBasicAuth("admin", "password")),\n)\nif err != nil {\n\tlog.Fatal(err)\n}\n\n// Batch insert documents\nresult, err := client.Batch(ctx, "products", antfly.BatchRequest{\n\tInserts: map[string]any{\n\t\t"prod:001": map[string]any{\n\t\t\t"name":  "Laptop",\n\t\t\t"price": 1299.99,\n\t\t},\n\t\t"prod:002": map[string]any{\n\t\t\t"name":  "Mouse",\n\t\t\t"price": 29.99,\n\t\t},\n\t},\n})`
  },
  {
    language: "TypeScript",
    code: `import { AntflyClient } from '@antfly/sdk';\n\nconst client = new AntflyClient({\n  baseUrl: 'http://127.0.0.1:8080',\n  auth: { username: 'admin', password: 'password' },\n});\n\n// Batch insert documents\nawait client.tables.batch('products', {\n  inserts: {\n    'prod:001': { name: 'Laptop', price: 1299.99 },\n    'prod:002': { name: 'Mouse', price: 29.99 },\n  },\n});`
  },
  {
    language: "Python",
    code: `from antfly import AntflyClient\n\nclient = AntflyClient(\n    base_url='http://127.0.0.1:8080',\n    username='admin',\n    password='password',\n)\n\n# Batch insert documents\nclient.batch(\n    table='products',\n    inserts={\n        'prod:001': {'name': 'Laptop', 'price': 1299.99},\n        'prod:002': {'name': 'Mouse', 'price': 29.99},\n    },\n)`
  },
  {
    language: "Rust",
    code: `use antfly_sdk::new_client;\nuse antfly_sdk::types::BatchRequest;\nuse serde_json::json;\nuse std::collections::HashMap;\n\nlet client = new_client("http://127.0.0.1:8080", reqwest::Client::new());\n\n// Batch insert documents. Each value is a JSON object.\nlet mut inserts = HashMap::new();\ninserts.insert(\n    "prod:001".to_string(),\n    json!({"name": "Laptop", "price": 1299.99}).as_object().unwrap().clone(),\n);\ninserts.insert(\n    "prod:002".to_string(),\n    json!({"name": "Mouse", "price": 29.99}).as_object().unwrap().clone(),\n);\n\nclient\n    .batch_write(\n        "products",\n        &BatchRequest {\n            inserts,\n            ..Default::default()\n        },\n    )\n    .await?;`
  }
]} />

### Query

<CodeTabs persistKey="sdk-lang" samples={[
  {
    language: "Go",
    code: `import "github.com/antflydb/antfly/go/pkg/sdk/query"\n\nfullText := query.NewQueryString("laptop")\nresults, err := client.Query(ctx, antfly.QueryRequest{\n\tTable:          "products",\n\tFullTextSearch: &fullText,\n\tLimit:          10,\n})\nif err != nil {\n\tlog.Fatal(err)\n}\n\nfor _, hit := range results.Responses[0].Hits.Hits {\n\tfmt.Printf("%s: %v\\n", hit.ID, hit.Source)\n}`
  },
  {
    language: "TypeScript",
    code: `const results = await client.query({\n  table: 'products',\n  full_text_search: { query: 'laptop' },\n  limit: 10,\n});\n\nfor (const hit of results?.hits?.hits ?? []) {\n  console.log(hit._id, hit._source);\n}`
  },
  {
    language: "Python",
    code: `results = client.query(\n    table='products',\n    full_text_search={'query': 'laptop'},\n    limit=10,\n)\n\nfor hit in results.responses[0].hits.hits:\n    print(hit.field_id, hit.field_source)`
  }
]} />

Rust has no query sample. Its client is generated straight from the OpenAPI
spec by progenitor, and the generated `QueryRequest` carries only `table`,
`fields`, `hierarchy`, `limit`, and `timeout_ms`, so it cannot express
`full_text_search` or `semantic_search`. Send search requests over HTTP
directly until the generated request type covers them.

## React Components

For search UIs, `@antfly/components` is a React component library with search boxes, facets, result lists, and answer boxes. [Add Search and AI Answers to Your Site](/docs/guides/site-search-and-answers) builds a page with it; the [React Antfly reference](/docs/ui/react-antfly) covers every component.

```bash
npm install @antfly/components @antfly/sdk
```
