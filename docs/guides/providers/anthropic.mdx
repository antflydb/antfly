The `anthropic` provider calls the Anthropic Messages API for generation.

## What It Provides

| Component | Inputs | Notes |
|---|---|---|
| Generator | Text, images | Streaming, function tools, and structured output |

Images can be JPEG, PNG, GIF, or WebP, in user messages only. Other media is
rejected before the request is sent.

## Credentials

`api_key`, defaulting to `ANTHROPIC_API_KEY`. The endpoint defaults to
`https://api.anthropic.com/v1`.

## Example

```json
{
  "generators": {
    "claude": {
      "provider": "anthropic",
      "model": "claude-sonnet-5-5",
      "api_key": "${secret:anthropic.api_key}",
      "max_tokens": 1024
    }
  }
}
```

## Extraction

Extract entities, relations, and structured records with a generated extractor
backed by a Claude generator. Use it as an `extractor` producer on an
enrichment, or send the `config` object with `inputs` added to `/ai/v1/extract`:

```json
{
  "type": "extractor",
  "config": {
    "method": "generated",
    "generator": {"provider": "anthropic", "model": "claude-sonnet-5-5", "api_key": "${secret:anthropic.api_key}", "max_tokens": 4096},
    "probabilities": "verdict_only",
    "schema": {
      "entities": ["person", "company"],
      "relations": [{"type": "works_for"}]
    }
  }
}
```

Admitted model families: Claude 3 and later (`opus`, `sonnet`, `haiku`, and `fable`), including dated snapshots. Output is returned through a forced tool call. Other models, and task variants such as
audio, image, search, or embedding models, are rejected when the config is
saved. `verdict_only` is required unless the model reports token
log-probabilities.
