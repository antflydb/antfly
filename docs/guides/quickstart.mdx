By the end of this page you have Antfly running on your machine with 10,000 Wikipedia articles loaded, and you have searched them by keyword, by meaning, and by what their pictures show, then asked a local model to answer a question from them, all on your own machine with no hosted service involved.

Allow 45 to 90 minutes on a laptop. The first full-text check takes seconds; model downloads and background indexing take most of the time, and slower hardware may need longer timeouts.

## Start Antfly

Start Antfly in standalone mode:

```bash
antfly standalone --inference-host-budget-mb 8192 2>&1 | tee "antfly.log"
```

If you installed with Homebrew, you can run Antfly as a service instead:

```bash
brew services start antfly
```

Standalone mode runs metadata, data, and Antfly Inference together. On macOS (Metal) and other GPU builds, model execution runs in a supervised child worker that standalone starts and restarts for you. The 8 GiB inference budget is what lets the all-local RAG step at the end run the embedding, reranking, and Gemma models in one request; drop the flag if you plan to use a hosted generator. The web dashboard is at `http://127.0.0.1:8080` once it is up. Every command on this page uses the numeric loopback address because it matches standalone's default bind on systems where `localhost` resolves to IPv6 first.

### Verify the basic data path

One document in, one document out, before anything expensive:

```bash
curl -fsS -X POST http://127.0.0.1:8080/db/v1/tables/hello \
  -H "Content-Type: application/json" \
  -d '{}'

curl -fsS -X POST http://127.0.0.1:8080/db/v1/tables/hello/batch \
  -H "Content-Type: application/json" \
  -d '{"inserts":{"first":{"title":"Hello","body":"Antfly is ready."}},"sync_level":"full_text"}'

antfly query --table hello \
  --full-text-search 'body:Antfly' \
  --fields 'title,body'
```

The last command returns the document with key `first`. If it does not, stop here and see [Troubleshooting](#troubleshooting).

### Install the text embedding model

Pull the text embedding model used for semantic search. [Antfly Inference](/docs/guides/inference) runs it locally under standalone, with no external API:

```bash
antfly inference pull hf:google/embeddinggemma-2:bf16-safetensors-bundle-v1
antfly inference list
```

EmbeddingGemma2 embeds text and images in the same 768-dimensional space and runs on CPU, Metal, or CUDA.

<Callout type="info">
The running process picks up the new model on its next model-list or inference
request. The Antfarm dashboard refreshes its model list about every 30 seconds,
so allow up to a minute for it to appear there.
</Callout>

## Download Sample Data

In a new terminal, download 10,000 Wikipedia articles enriched with thumbnail images:

```bash
curl -L -o wiki-articles.jsonl https://cdn.antfly.io/datasets/wiki-articles-10k-v001.json
head -n 1 wiki-articles.jsonl | jq '.'
```

One article per line, each with `title`, `body`, and `url`. 2,446 of the 10,000 also carry a `thumbnail_url`, which the image search step uses later.

## Create a Table

Create a table with a text embedding index for semantic search. Each step shows the CLI and the equivalent HTTP request; the [SDKs](/docs/reference/sdks) for Go, TypeScript, Python, and Rust take the same request bodies.

<Tabs defaultValue="cli">
  <TabsList>
    <TabsTrigger value="cli">CLI</TabsTrigger>
    <TabsTrigger value="curl">cURL</TabsTrigger>
  </TabsList>

  <TabsContent value="cli">
```bash
antfly table create --table wikipedia \
  --index '{
    "name": "title_body",
    "type": "embeddings",
    "template": "{{title}} {{body}}",
    "embedder": {
      "provider": "antfly",
      "model": "google/embeddinggemma-2:bf16-safetensors-bundle-v1"
    },
    "chunker": {
      "provider": "antfly",
      "text": {
        "target_tokens": 200,
        "overlap_tokens": 25
      }
    }
  }'
```
  </TabsContent>

  <TabsContent value="curl">
```bash
curl -X POST http://127.0.0.1:8080/db/v1/tables/wikipedia \
  -H "Content-Type: application/json" \
  -d '{
    "indexes": {
      "title_body": {
        "type": "embeddings",
        "template": "{{title}} {{body}}",
        "embedder": {
          "provider": "antfly",
          "model": "google/embeddinggemma-2:bf16-safetensors-bundle-v1"
        },
        "chunker": {
          "provider": "antfly",

            "target_tokens": 200,
            "overlap_tokens": 25

        }
      }
    }
  }'
```

Verify the table and index were created:

```bash
antfly table list
antfly index list --table wikipedia
```

`title_body` is the embeddings index you created. `full_text_index_v0` came free: every table gets one, and it is what the keyword query below runs against.

## Load Data

```bash
# Load all 10,000 articles using the title as the document ID
antfly load --table wikipedia \
  --file wiki-articles.jsonl \
  --id-field title \
  --sync-level full_text
```

The CLI reads the JSONL and batches it for you. `--sync-level full_text` returns once each batch is keyword-searchable; embeddings keep generating in the background. (An application that owns its own ingestion uses the SDK [batch operations](/docs/api/data-operations) with bounded batches and retries.)

Wait until 10% of documents have searchable embeddings:

```bash
antfly index wait --table wikipedia \
  --index title_body \
  --until source-covered=10% \
  --timeout 45m
```

Continue as soon as it returns; results improve as the rest of the corpus is indexed, and `antfly index list --table wikipedia` shows progress (counts are per chunk, so they can exceed the article count). Use `--until complete` to wait for everything. If the wait times out, see [Troubleshooting](#troubleshooting).

### Semantic Search

Find articles semantically similar to a natural language query:

```bash
antfly query --table wikipedia \
  --semantic-search "anatomy and physiology" \
  --indexes "title_body" \
  --fields "title,url" \
  --limit 5
```

## Hybrid Search & Reranking

One query can run the keyword and semantic searches together; Antfly fuses the two ranked lists with Reciprocal Rank Fusion. The Qwen3 text reranker then rescores each query-document pair to improve the ordering of those candidates.

Pull the reranker model:

```bash
antfly inference pull hf:ggml-org/Qwen3-Reranker-0.6B-Q8_0-GGUF:gguf:Q8_0 --tasks rerank
```

The first query loads the model, so it can take tens of seconds.

```bash
antfly query --table wikipedia \
  --full-text-search 'body:Einstein' \
  --semantic-search "theory of relativity and physics" \
  --indexes "title_body" \
  --fields "title,url" \
  --limit 10 \
  --reranker '{
      "provider": "antfly",
      "model": "ggml-org/Qwen3-Reranker-0.6B-Q8_0-GGUF:gguf:Q8_0",
      "field": "body"
    }' \
  --pruner '{"min_score_ratio": 0.01}'
```

Reranking changes the order and keeps the count. Pruning changes the count: `min_score_ratio` keeps only results scoring at least that fraction of the top result, and `max_score_gap_percent` stops at the first sharp drop. [Tune Hybrid Search](/docs/guides/hybrid-search) covers both in depth.

## Image Search

EmbeddingGemma2 places text and images in one embedding space, so you can describe a picture in words and get the articles whose thumbnails match.

<Steps>
### Add an image index to your table

Add a second index with the same [EmbeddingGemma2 model](#install-the-text-embedding-model), this time embedding each article's thumbnail:

```bash
antfly index create --table wikipedia \
  --index thumbnail \
  --type embeddings \
  --coverage-policy partial \
  --template "{{#if thumbnail_url}}{{remoteMedia url=thumbnail_url}}{{/if}}" \
  --embedder '{"provider": "antfly", "model": "google/embeddinggemma-2:bf16-safetensors-bundle-v1"}' \
  --distance-metric cosine
```

Articles without thumbnails are skipped. Wait for 250 searchable images:

```bash
antfly index wait --table wikipedia \
  --index thumbnail \
  --until searchable-artifacts=250 \
  --timeout 45m
```

### Search by visual content

Describe what you want to see:

```bash
antfly query --table wikipedia \
  --semantic-search "map of a country" \
  --indexes "thumbnail" \
  --fields "title,url,thumbnail_url" \
  --limit 5
```

Concrete visual descriptions ("red sports car", "mountain landscape") work better than abstract ones. The same pipeline enriches your own documents: PDFs and scans are read with built-in OCR or a connected provider, and audio is transcribed before indexing. See [Multimodal Embeddings](/docs/guides/multimodal) and [Index Recorded Calls and Podcasts](/docs/guides/transcription).
</Steps>

## RAG (Retrieval-Augmented Generation)

The retrieval agent plans the query, runs the search, and hands the results to a local language model to write the answer.

<Steps>
### Pull a generation model

```bash
antfly inference pull hf:ggml-org/gemma-4-E4B-it-GGUF:gguf:Q4_0 \
  --tasks generate \
  --projector auto
```

`--projector auto` includes image and audio input; `--projector none` is a smaller, text-only download. To use a hosted model instead, skip to [RAG with alternative providers](#rag-with-alternative-providers).

### Build a query and generate an answer

Give Gemma an intent and a table. The retrieval agent delegates query planning
to the query builder, searches, and answers from the results.

<Tabs defaultValue="cli">
  <TabsList>
    <TabsTrigger value="cli">CLI</TabsTrigger>
    <TabsTrigger value="curl">cURL</TabsTrigger>
  </TabsList>

  <TabsContent value="cli">
```bash
antfly agents retrieval --table wikipedia \
  --intent "What are the major events in Korean history?" \
  --fields "title,body" \
  --limit 5 \
  --generator '{
    "provider": "antfly",
    "model": "ggml-org/gemma-4-E4B-it-GGUF",
    "max_tokens": 512
  }' \
  --max-internal-iterations 8 \
  --streaming
```
  </TabsContent>

  <TabsContent value="curl">
```bash
curl -N -X POST http://127.0.0.1:8080/db/v1/agents/retrieval \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "query": "What are the major events in Korean history?",
    "queries": [{
      "table": "wikipedia",
      "fields": ["title", "body"],
      "limit": 5
    }],
    "generator": {
      "provider": "antfly",
      "model": "ggml-org/gemma-4-E4B-it-GGUF",
      "max_tokens": 512
    },
    "max_internal_iterations": 8,
    "stream": true,
    "steps": {
      "generation": {"enabled": true}
    }
  }'
```
  </TabsContent>

</Tabs>

Both commands stream Server-Sent Events as each step completes and end with `event: done`. Use `--no-streaming` (or `"stream": false`) to get one JSON body with the answer and its sources. To see the query the agent would run without running it, use `antfly agents query-builder` with the same `--table`, `--intent`, and `--generator`.

### Evaluation

`steps.eval` scores retrieval and generation quality in the same request. The
CLI has no evaluation flag, so send it on the API request:

```bash
curl -N -X POST http://127.0.0.1:8080/db/v1/agents/retrieval \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "query": "What are the major events in Korean history?",
    "queries": [{
      "table": "wikipedia",
      "semantic_search": "What are the major events in Korean history?",
      "indexes": ["title_body"],
      "fields": ["title", "body"],
      "limit": 5
    }],
    "generator": {"provider": "gemini", "model": "gemini-2.5-flash"},
    "stream": true,
    "steps": {
      "generation": {"enabled": true},
      "eval": {
        "evaluators": ["faithfulness", "relevance"],
        "judge": {"provider": "gemini", "model": "gemini-2.5-flash"}
      }
    }
  }'
```

The scores arrive as an `eval` event in the stream. Judge metrics include `relevance`, `faithfulness`, `completeness`, and `citation_quality`; with `ground_truth.relevant_ids` you also get retrieval metrics such as `recall`, `ndcg`, and `mrr`.
</Steps>

## Troubleshooting

### `antfly` is not found after the Linux install

The installer puts the binary in `~/.local/bin`. Add it to the current shell and retry:

```bash
export PATH="$HOME/.local/bin:$PATH"
antfly --version
```

### Antfly reports a legacy data directory

Antfly will not overwrite a data directory from the old Go runtime. Leave it in place, back it up with that runtime if you need it, and start this quickstart on a fresh directory:

```bash
antfly standalone --data-dir "$HOME/.antfly-zig" 2>&1 | tee antfly.log
```

Models stay in `~/.antfly/inference/models` unless you pass `--models-dir` or set `ANTFLY_INFERENCE_MODELS_DIR`.

### `MODEL_NOT_FOUND`

Confirm the model is installed and check the model directory the startup log printed:

```bash
antfly inference list
grep -F 'standalone inference paths' antfly.log
```

Pull it again, or point at the right directory with `antfly standalone --models-dir <path>`.

### An index remains pending or `index wait` times out

Wait for the readiness threshold each step names before moving on. `queryable_partial` is safe to query while coverage grows, but an empty published generation cannot produce results. If `index wait` times out, capture the full status and the recent log:

```bash
antfly index list --table wikipedia --output json | jq '.'
grep -E 'watchdog|derived worker|NotFound|EnrichmentWaitTimeout' antfly.log | tail -n 100
```

Chunk and vector counts exceeding the article count is normal. Counts that keep growing on unchanged data, coverage that never advances, or a `ready` index dropping back to `pending` is a bug: report it with the JSON status, the log excerpt, the Antfly version, and the startup command.

### Startup reports a port conflict or memory error

Stop whatever holds ports 8080 or 4200, or pick others with `--port` and `--health-port`. For memory errors, stop other large local models, or retry with a smaller model or a larger `--inference-host-budget-mb`.

### Stop the quickstart

Press <kbd>Ctrl</kbd>+<kbd>C</kbd> in the standalone terminal, or with Homebrew services:

```bash
brew services stop antfly
```

## Give Your Agent the Antfly Skill

Everything you just did by hand, a coding agent can do for you. The [Antfly skill](https://github.com/antflydb/antfly-skills) carries verified, current knowledge of Antfly's APIs, query shapes, React components, and operations, for Claude Code, Cursor, Codex, and other agent harnesses:

```bash
npx skills add antflydb/antfly-skills
```

From here your agent can create tables, build indexes, and write queries against the instance you just started.
