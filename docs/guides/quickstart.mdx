By the end of this page you have Antfly running on your machine with 10,000 Wikipedia articles loaded, and you have searched them by keyword, by meaning, and by what their pictures show, then asked a local model to answer a question from them. Every step runs on your laptop. Nothing leaves it.

## Install Antfly

```bash
curl -fsSL https://releases.antfly.io/antfly/latest/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
antfly --version
```

On macOS, `brew install antflydb/taps/antfly` works too. On Windows, run the
script inside WSL2. Docker and every archive are on the
[Downloads page](/docs/downloads).

## Start Antfly

Start Antfly in standalone mode:

```bash
antfly standalone --inference-host-budget-mb 8192 2>&1 | tee "antfly.log"
```

If you installed with Homebrew, you can run Antfly as a service instead:

```bash
brew services start antfly
```

Standalone mode runs metadata, data, and Antfly Inference in one process. The 8 GiB inference budget is what lets the all-local RAG step at the end run the embedding, reranking, and Gemma models in one request; drop the flag if you plan to use a hosted generator. The web dashboard is at `http://localhost:8080` once it is up.

### Verify the basic data path

One document in, one document out, before anything expensive:

```bash
curl -fsS -X POST http://localhost:8080/db/v1/tables/hello \
  -H "Content-Type: application/json" \
  -d '{}'

curl -fsS -X POST http://localhost:8080/db/v1/tables/hello/batch \
  -H "Content-Type: application/json" \
  -d '{"inserts":{"first":{"title":"Hello","body":"Antfly is ready."}},"sync_level":"full_text"}'

antfly query --table hello \
  --full-text-search 'body:Antfly' \
  --fields 'title,body'
```

The last command returns the document with key `first`. If it does not, stop here and see [When Something Goes Wrong](#when-something-goes-wrong).

### Install the embedding model

Pull the multimodal model used for both text and image search. [Antfly Inference](/docs/guides/inference) runs it inside the same process, with no external API:

```bash
antfly inference pull antflydb/clipclap:gguf:Q4_K
antfly inference list
```

If the running process does not pick up the new model, restart it once before creating the index.

## Download Sample Data

In a new terminal, download 10,000 Wikipedia articles enriched with thumbnail images:

```bash
curl -L -o wiki-articles.jsonl https://cdn.antfly.io/datasets/wiki-articles-10k-v001.json
head -n 1 wiki-articles.jsonl | jq '.'
```

One article per line, each with `title`, `body`, and `url`. 2,446 of them also carry a `thumbnail_url`, which the image search step uses later.

## Load Data

```bash
# Load all 10,000 articles using the title as the document ID
antfly load --table wikipedia \
  --file wiki-articles.jsonl \
  --id-field title \
  --sync-level full_text
```

The CLI reads the JSONL and batches it for you. `--sync-level full_text` returns once each batch is keyword-searchable; embeddings keep generating in the background. (An application that owns its own ingestion uses the SDK [batch operations](/docs/api/data-operations) with bounded batches and retries.)

Embeddings indexes publish progressively: as soon as a checkpointed slice of the corpus is embedded, semantic queries can run against it while the rest catches up. Wait for that first queryable slice:

```bash
antfly index wait --table wikipedia \
  --index title_body \
  --until queryable \
  --timeout 20m
```

Continue as soon as it returns. Result counts and rankings improve as coverage grows; `antfly index list --table wikipedia` shows progress, and `--output json` shows the full status. When an application needs the whole corpus covered before it queries, wait with `--until complete` for the `ready` state instead, or create the index with `publication_policy: atomic` so nothing is served until the build is complete. Time to the first queryable slice depends on your hardware. If the wait times out, do not press on; see [When Something Goes Wrong](#when-something-goes-wrong).

In the status output, `INDEXED` and `VISIBLE` count chunks and vectors, not articles, so they can exceed 10,000. `queryable_partial` means safe to query but incomplete; `ready` means fully covered.

## Hybrid Search & Reranking

One query can run the keyword and semantic searches together; Antfly fuses the two ranked lists with Reciprocal Rank Fusion. A reranker then rescores the fused candidates with a cross-encoder that reads each query-document pair in full.

Pull the reranker model:

```bash
antfly inference pull --tasks rerank --variants f32 cross-encoder/ms-marco-MiniLM-L6-v2
```

<Callout type="info">
If Antfly doesn't detect the new model, restart `antfly standalone`.
</Callout>

## RAG (Retrieval-Augmented Generation)

The retrieval agent runs search, reranking, and pruning, then hands the survivors to a language model to write the answer.

<Steps>
### Pull a generation model

```bash
antfly inference pull ggml-org/gemma-4-E4B-it-GGUF:gguf:Q4_K_M
```

`ggml-org/gemma-4-E4B-it-GGUF` runs on Antfly Inference and handles the whole flow: classification, generation, reasoning, and follow-up questions. The generator config below caps output at 128 tokens so local latency stays predictable. Hosted providers are [one section down](#rag-with-alternative-providers).

### Structured output

`--no-streaming` returns one JSON body with the answer and its sources instead of streamed text:

```bash
antfly agents retrieval --table wikipedia \
  --semantic-search "Explain the theory of relativity" \
  --indexes "title_body" \
  --fields "title,body,url" \
  --limit 5 \
  --generator '{"provider": "gemini", "model": "gemini-2.5-flash"}' \
  --no-streaming --generate
```

### Evaluation

`--eval` scores retrieval and generation quality in the same request:

```bash
antfly agents retrieval --table wikipedia \
  --semantic-search "What are the major events in Korean history?" \
  --indexes "title_body" \
  --fields "title,body" \
  --limit 5 \
  --generator '{"provider": "gemini", "model": "gemini-2.5-flash"}' \
  --generate \
  --eval '{
    "evaluators": ["faithfulness", "relevance"],
    "judge": {"provider": "gemini", "model": "gemini-2.5-flash"}
  }'
```

The evaluators:
- **Retrieval metrics** (require `ground_truth.relevant_ids`): `recall`, `precision`, `ndcg`, `mrr`, `map`
- **LLM-as-judge metrics** (require `judge` config): `relevance`, `faithfulness`, `completeness`, `coherence`, `safety`, `helpfulness`, `correctness`, `citation_quality`
</Steps>

## When Something Goes Wrong

### `antfly` is not found after the Linux install

The installer puts the binary in `~/.local/bin`. Add it to the current shell and retry:

```bash
export PATH="$HOME/.local/bin:$PATH"
antfly --version
```

### Antfly reports a legacy data directory

Antfly will not overwrite a data directory from the old Go runtime. Leave it in place, back it up with that runtime if you need it, and start this quickstart on a fresh directory:

```bash
antfly standalone --data-dir "$HOME/.antfly-zig" 2>&1 | tee antfly.log
```

Models stay in `~/.antfly/inference/models` unless you pass `--models-dir` or set `ANTFLY_INFERENCE_MODELS_DIR`.

### `MODEL_NOT_FOUND`

Confirm the model is installed and check the model directory the startup log printed:

```bash
antfly inference list
grep -F 'standalone inference paths' antfly.log
```

Pull it again, or point at the right directory with `antfly standalone --models-dir <path>`.

### An index remains pending or `index wait` times out

`queryable_partial` is safe to query while coverage grows; `pending` is not. If `index wait --until queryable` times out, capture the full status and the recent log:

```bash
antfly index list --table wikipedia --output json | jq '.'
grep -E 'watchdog|derived worker|NotFound|EnrichmentWaitTimeout' antfly.log | tail -n 100
```

Chunk and vector counts exceeding the article count is normal. Counts that keep growing on unchanged data, coverage that never advances, or a `ready` index dropping back to `pending` is a bug: report it with the JSON status, the log excerpt, the Antfly version, and the startup command.

### Startup reports a port conflict or memory error

Stop whatever holds ports 8080 or 4200, or pick others with `--port` and `--health-port`. For memory errors, stop other large local models, or retry with a smaller model or a larger `--inference-host-budget-mb`.

### Stop the quickstart

Press <kbd>Ctrl</kbd>+<kbd>C</kbd> in the standalone terminal, or with Homebrew services:

```bash
brew services stop antfly
```
