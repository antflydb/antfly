Antfly is a database with a complete inference and retrieval pipeline built in: full-text, vector, and graph indexes in one engine, with the models that chunk, embed, rerank, and extract running inside it. You insert documents; the engine does the rest. It runs as a single binary on your laptop, as a cluster on Kubernetes, or hosted in [Antfly Cloud](/cloud).

In a second terminal, create a table (a full-text index comes with it), insert a document, and search it:

```bash
curl -X POST http://localhost:8080/db/v1/tables/knowledge \
  -H "Content-Type: application/json" \
  -d '{}'

curl -X POST http://localhost:8080/db/v1/tables/knowledge/batch \
  -H "Content-Type: application/json" \
  -d '{"inserts":{"doc-1":{"content":"Antfly keeps the retrieval pipeline inside the engine."}},"sync_level":"full_text"}'

curl -X POST http://localhost:8080/db/v1/query \
  -H "Content-Type: application/json" \
  -d '{"table":"knowledge","full_text_search":{"query":"content:pipeline"},"fields":["content"],"limit":5}'
```

That is the whole loop. The [Quickstart](/docs/guides/quickstart) does it with 10,000 Wikipedia articles and adds semantic search, hybrid search with reranking, [image search](/docs/guides/quickstart#image-search), and [RAG](/docs/guides/quickstart#rag-retrieval-augmented-generation). The web dashboard is at `http://localhost:8080` while the engine runs.

## What Antfly is

- **One engine, several indexes.** `full_text` (BM25), `embeddings` (vector, RaBitQ-compressed), and `graph` (traversal and pathfinding) are index types on the same table and are fused in one query plan. See the [Document Engine guide](/docs/guides/document-engine) for how mappings, search modes, filters, sorting, and pagination compose.
- **Inference inside the engine.** Chunking, embedding, reranking, summarization, and entity extraction run as background enrichers and query processors using [Antfly Inference](/docs/guides/inference), which ships quantized models in the binary. External providers (Ollama, OpenAI, Bedrock, Gemini, Anthropic) plug in the same way.
- **Any shape of data.** Text, PDFs (with local OCR when needed), images, audio, and video, referenced by URL or inserted directly. See [Multimodal Embeddings](/docs/guides/multimodal).
- **Built for agents.** Streaming RAG, retrieval and query-builder agents, evaluation metrics, and an MCP surface. See [RAG in the Quickstart](/docs/guides/quickstart#rag-retrieval-augmented-generation).
- **Distributed by design.** Multi-Raft consensus, horizontal sharding with online splitting, cross-shard write transactions, and a Kubernetes [operator](/docs/operator) with autoscaling. [Architecture](/docs/architecture) explains how it fits together.
- **Local-first too.** [Antfly Lite](/docs/guides/lite) embeds the engine in a single `.aflite` file for desktop and edge applications.
