## Defects Found

The verbatim inventory has 162 bulleted entries covering production and harness defects VOPR exposed while composing scenarios (v9 through v53). Most entries say explicitly whether the defect was a production bug or a harness/fixture/oracle defect; that distinction is preserved below. The bounded independent-domain model campaigns completed without an additional semantic product-property failure or replay divergence, and reports keep that result distinct from these defects.

### Production: correctness, safety, and fencing

- **Merge acknowledged without follower apply.** `DataServer` used the direct-DB `MergeCoordinator` even with data Raft enabled. Fixed with replicated source prepare/finalize/rollback controls, receiver checkpoints, Raft-written copies, durable source fencing, snapshot-carried control state, and a version-3 Raft batch capability barrier (older replicas could otherwise ignore an unknown private JSON field and apply an empty command).
- **Merge catch-up ignored current JSON batch envelopes** (parsed only legacy `put:`/`del:`), so merges could finalize without current writes; superseded by committed-outcome snapshot and artifact transfer, because raw requests are not a safe materialized-effects log.
- **Receiver range coverage used as proof of bootstrap** — unsound when the receiver pre-covers the donor; now an explicit durable bootstrap-complete marker plus applied-index watermark.
- **Primary-only merge lost graph edges** after cutover; bootstrap now imports graph/embedding artifacts from the retained donor DB lease before publishing the marker.
- **Rolled-back receiver checkpoint blocked every later transition** (`ConflictingMergeTransition`); a terminal rolled-back receipt is now replaceable only by a different transition's `accept` at the restored base range.
- **`finalize_merge` retry after restart was not idempotent**; matching replicated terminal receipts are now the retry boundary.
- **Split delta sequencing** (`SplitReplicationSequenceGap`): sparse Raft-index watermarks were checked as `sequence == applied + 1`. Each delta now carries its exact predecessor, behind a durable v4 protocol barrier. Follow-on fixes: destination checkpoints projected into the Raft apply store; post-restart background projection could widen a finalized source from `[doc:a,doc:t)` back to `[doc:a,)`, so the apply-store range is authoritative for terminal splits.
- **Stale CDC worker could publish checkpoint progress**: the snapshot runner advanced durable source progress after target apply without rechecking `WorkPermit`. It now revalidates between apply and checkpoint; v47 proves `CdcWorkLeaseLost` at durable offset 0 and one idempotent replay.
- **In-flight authorization not rechecked**: global-query NDJSON lines (v38) and multi-stage graph target authorization used only the ingress identity snapshot. They now intersect admitted scope with current authority — later grants cannot broaden a request; revocation, deletion, and expiry fail closed before the next protected operation.
- **Exact-group join fallback to a foreign local DB**: an unexpected remote HTTP status became a null route, and the coordinator then ran the foreign group locally. Now typed absence/unavailability is preserved and unexpected remote responses fail closed (v33).
- **Server TLS fail-open**: supplying cert/key paths only warned and served plaintext; binding now rejects incomplete TLS configuration (explicit TLS termination remains the supported boundary).
- **Local reranking accepted wrong-length or non-finite score vectors**; now `InvalidRerankerResponse`.
- **Persistent object-range cache invisible to `ResourceManager`**; queue memory now uses an exactly-once `lake_range_cache_queue` reservation and workers reserve capacity growth before file I/O.
- **External modeled storage lacked a durable physical-root incarnation**, risking writer-identity reuse; `DB.OpenOptions` now accepts one.
- **External-data-plane metadata left its local transition executor alive**, causing writer conflicts with real DataServers on the same roots; external mode now retires it.
- **Transaction recovery retained the address of a by-value `DB` wrapper** (ReleaseSafe poisoned it); recovery now owns a separately allocated, atomically bound callback context. Similar stale-pointer fixes: audio-provider `ActiveRuntime`; media-runtime globals published before every provider loaded.
- **Raft apply**: a ReadState-only Ready was treated as empty, stranding strong-read waiters (looked like v16 owner non-recovery); `ResourceBudgetExceeded` acquiring an apply writer was terminal, now normalized to retryable `RaftApplyWriterUnavailable` with exact retry checkpoint (a non-idempotent transform is not applied twice).
- **Data-Raft stable-epoch fast path treated peer transport endpoints as placement identity**; a separate transport fingerprint now tracks Raft URLs. (Recorded as still needing a focused endpoint-rotation regression before being promoted as verified.)
- **Replicated split-action lane double-release** after inline job failure; lane release is now idempotent and checks `lane_held`.
- **Finalizer result leak** (all 64 joined hits in the first v20 run) when the post-persistence hook failed; **join core entry point** silently downgraded durable shuffle to transient execution by not binding `JoinContext`.

### Production: availability and API contract

- **Public reads/joins at non-owner nodes** hit the local RawNode and returned `UnknownGroup` as HTTP 500; public Provisioned operations and exact-group join callbacks now route to the current owner, while local routes still go through the resident DB/read-admission owner (the first repair bypassed it). Group-local helpers no longer claim outer read admission unconditionally.
- **ReadIndex treated as complete when enqueued**, and strong graph phases fell back from `NotLeader` to stale results; now completes only after the matching ReadState is applied and full-index visibility is reached. This converted a partial HTTP 200 into a complete v13 result. Later, an acknowledged `full_index` batch was point-readable while a match-all query returned 200 with zero hits; preflight and group queries now use the same combined barrier (v19).
- **Explicit metadata refresh used the cached path** (`refreshRemoteMetadataSnapshot`); it now invalidates head and snapshot first.
- **Non-member coordinators trusted a cached Raft leader hint indefinitely** after leader reconstruction; they now resolve the leader from current merged metadata (v32).
- **Opaque HTTP 500s for availability faults**: graph fanout `SendFailed`, terminal `TopologyChanged`/`UnknownGroup`, global-query `SendFailed` (v39), shuffle completion and the join's primary left-side query (v32), and internal join resource/ownership failures (v33) now normalize to typed retryable `DistributedQueryUnavailable` / 503 `distributed_query_unavailable` with no partial body. Public point reads/queries preserve typed 409/503/504, retrying point reads only as idempotent GETs.
- **Pre-proposal readiness branches returned `RaftBatchWriteOutcomeUnknown`**; now retryable `LeaderUnavailable`, with the ambiguous contract kept for post-acceptance failures.
- **Wire-contract mismatches**: graph-expand handler emitted nested `graph_result`; graph-hydrate handler emitted nested `incoming_index_identity` instead of flattened `incoming_index_incarnation`/`incoming_index_config_hash` (found replaying v27 after v38); `GraphResultNode` required nullable `path`/`path_edges`. Handlers now use canonical encoders.
- **Unconditional graph hydration** even when `include_documents` was false, enlarging the ownership window and exposing an LSM root-writer race.
- **Generator 300-second timeout** overrode the borrowed `httpx.Client` timeout; **canceled HTTP/1 reads** surfaced `RecvFailed`/`InvalidResponse` instead of `Canceled`; **query-embedding cache** used `waitUncancelable` with no deadline; **table-write retry loops** swallowed `Canceled`; **v30 join handlers** discarded request cancellation/deadline by running with the process-scoped `JoinContext`.
- **Teardown/lifetime**: listener shutdown closed the socket before waking accept (`BADF`); wake through an unacquired `HttpRuntime` lease; shared httpx clients admitted requests during provider teardown; nested public→metadata→data-Raft client lanes needed publish-before-drain shutdown plus wakeable cancellation tokens; DB transaction-maintenance workers, enrichment, and DataServer needed a `beginTeardown` phase; threaded durable-job lane held its reap mutex while awaiting (deadlock); serverless public-catalog double teardown; canceled group-status refresh leaked `doc_identity_lifecycle` strings.

### Production: determinism (hidden host time, threads, and I/O)

A large class: production code borrowing `VoprIo` still escaped to host clocks, native threads, or hidden `Threaded` executors, which broke exact replay or let native work race the scheduler. Fixed instances include DataServer cache TTLs/repair/status/metrics and `RemoteMetadataSource` budgets; data-Raft deadlines, timestamps, and `nanosleep` retries; JWT signing from host realtime; transition retry jitter from `std.Options.debug_io.random`; hosted query `took_ms`; graph coordinator deadlines; public-query topology retry; distributed join deadlines (now relative budgets on the wire); host filesystem capacity serialized into DataServer status (now an operator-owned `CapacitySource`); generation-chain `nanosleep`; httpx POSIX reads/listen and its global `Threaded` wake connection; `HttpRuntime`'s three hidden executors; Raft frame driver `std.Thread` workers; native `StdHttpExecutor` for data-Raft and cross-owner forwarding; the durable apply store's private `std.Io.Threaded`; native Lite's own `Threaded`; raw POSIX directory creation/fsync; and v53's six managed-index leaks (source-owned `Threaded` reconciliation, raw threads in configured-index opens, hidden-executor `_index_incarnation`, platform-clock enrichment timestamps, realtime deadlines, and physical duration telemetry in runtime status). `WriteCacheTransitionLocks` ordered mutexes by allocator address; it now uses the semantic role order (write cache, then startup cache).

Related: a borrowed-scheduler resident-open used a native mutex wait that pinned the single scheduler (now `tryLock` returning retryable `StorageReadTemporarilyUnavailable`); `FileStore` called a foreign archive's `std.Io` vtable directly, turning `FileNotFound` into `EndOfStream` — matching layouts/toolchains alone does not make error-returning vtable calls safe across independent Zig compilation units.

### VoprIo model and engine defects

- **Identity model revisions** (each found by a v12 divergence): pointer-derived futex identity reused across epochs (model v2); process-global task/futex ordinals aliased unrelated operations at choice 36,298 (model v3: parent-local epochs); opposite spawn order of distinct roles (model v4: ASLR-independent callsite); same-listener clients with identical first payloads exchanging connection identity (model v5); outbound retry becoming the child of its prior socket (model v6: immutable resource-creation owner).
- **Replay comparison**: selected-transition metadata not compared (choice 37,718: same packet ID, 315 vs 641 bytes) — now `ReplaySelectedTransitionDiverged`; packet byte count used as payload evidence — now a semantic digest; whole-history JSONL rendering reached roughly 14 GB and more than an hour for a 320,000-transition history — now direct canonical comparison.
- **Network/socket model**: global listener/connection/packet IDs; connect-before-accept skipped a readiness transition; FIN overtook queued data; historical rather than live socket accounting; listener close leaked queued accepted handles; FIN vs read-side abandonment conflated (v25/half-close); semantic-stream selector missed markers fragmented across writes (now per-connection KMP state); whole-network outages too broad for graph/split (now endpoint/direction/stream scoped).
- **Scheduler/tasks**: stolen wakes (now wait-sequence cutoffs); teardown always picked the first stable task (now round-robin); canceled tasks skipped `defer` cleanup (now a bounded cancel-and-drain suffix); `Future.await` as a cancellation point let parents unwind before children; ReleaseSafe current-task identity corruption across context switches; counterfactual analysis lacked a total experiment budget.
- **Filesystem model**: single aggregate file-lock owner; ignored lock options on open/create; rename injection used an error outside Zig's contract (now `HardwareFailure`).
- **Trace retention**: per-transition name allocation pushed record-only memory above 13 GiB in the first deep v53 gate; `Trace` now interns strings. Modeled capacity now counts allocated 4 KiB blocks to avoid one-byte differences from unique temp-path names.

### Harness, fixture, and oracle defects (not product failures)

Recorded so the same mistakes aren't repeated: scenario modules not forced into test discovery (green commands ran zero tests); runner asserted the oracle before proving the failure replays (now replays first); vacuous coverage claims later given executable witnesses (v41 adjacent cache instead of node 1's `ApiHttpServer` cache, fixed by v49; v50 publication-progress CAS never exercised; focused `source_crash` and `topology_change` modes that didn't exercise the claimed boundaries; v46 `WorkPermit` wrapper replacing rather than composing the lease permit); coordinators chosen by ordinal that hosted the target range; v16 prototype that rebound to new ephemeral ports (modeled a topology change, not a restart — now stable-bind); 1 ns polling barriers starving 1 ms production timers; accelerated 1 ms Raft driver vs production 100 ms cadence; oracles with exact counts that ignored a legitimate duplicate (v43 now requires exactly four batches); v44 restart racing unrelated workload handlers and unsafe `primaryGroupProgress` sampling during reconstruction; missing internal-service credentials in fixtures; out-of-range fixture keys (v42); a reduced serializer instead of canonical `encodeBatchRequest`; `std.testing.allocator` stack-trace mutex deadlocking fibers; 4 MiB fiber stack overflow (deployment history now uses 8 MiB); macOS ReleaseSafe CLI/meta build ceiling raised from 12 GiB to 16 GiB after a 15.05 GiB peak; v30 `@intCast` of high-bit job IDs (now `@bitCast`); poisoned optional Futures during early cancellation; independent `initialized`/`paused` booleans replaced by an explicit `starting`/`running`/`quiescing`/`stopped` lifecycle.
