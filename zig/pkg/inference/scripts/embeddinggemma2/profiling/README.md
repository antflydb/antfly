# EmbeddingGemma2 CUDA qualification

This directory retains the comparisons, numerical gates and aggregate results
for the shipped L4 CUDA encoder profile. Model weights, HLO/executable exports,
generated media, full output vectors, profiler traces and intermediate experiment
results belong under ignored `evidence/`.

- [Automatic defaults](AUTOMATIC_DEFAULTS.md): qualified hardware/shapes,
  override behavior, fresh legacy/automatic/explicit measurements and memory
  tradeoffs. `compare_automatic_model.py` runs the regression campaign using
  fixtures generated by `zig/lib/pjrt/tools/media_inputs.py --include-text`.
- [Global attention](GLOBAL_ATTENTION.md): bounded packed-GEMM implementation,
  scratch ownership, operator checks and native CUDA/PJRT comparisons.
  `make_global_suite.py` supplies performance and odd-length/mask/replay inputs;
  `compare_global_model.py` runs the production encoder comparison. The isolated
  Zig benchmark checks numerical outputs, masking and independent CUDA contexts.
- [Media qualification](MEDIA.md): end-to-end image/audio measurements,
  independent CPU-oracle checks and the remaining strict BF16 audio failures.
  `media-acceptance.json` freezes the numerical and timing gates;
  `media-fp32-diagnostic.json` defines a separate precision diagnostic.
  Reproduction tools are documented in the
  [PJRT tools guide](../../../../../lib/pjrt/tools/README.md).
- `check_softmax_scope.py` verifies that the existing vision softmax remains
  bit-identical to the baseline compiled entry point. It is separate from the
  new normalized global-softmax entry point.

The JSON files alongside each report retain aggregate measurements, artifact
hashes and qualification status. The production CUDA implementation is under
`src/ops/cuda/`; no experimental attention prototype is part of dispatch.
