# Inference model-lock suspension contracts

A synchronous borrowed provider now parks its existing execution grant only when InferenceExecutionControl.lock encounters a contended native model gate. Original control cancellation/deadline checks continue while runnable-only checkpoints are suspended. Reacquisition goes through the original inference enter callback before execution continues; failed reacquisition invalidates the child phase, leaves final retirement to its owning caller, releases an acquired model lock, and rejects/disposes any published provider response even if a backend swallowed the failure. No additional scheduler token or deadline is created.

Native macOS and pinned Nix/glibc aarch64-linux-gnu focused antfly-inference-parent-phase-test gates pass all nine tests (four host plus five wire), zero skips/failures/leaks, exit 0. Results and full logs retain exact commands and the two changed source hashes. Contract fixtures verify that the holder releases its model lock only after the borrower parks, normal inference/query restoration, cancellation while parked, unlocked failure paths, callback removal, and response destruction after swallowed failed resume. These use deterministic callback fixtures; they do not prove real scheduler metrics or contention/fairness for numerical model workloads.

Real API capsule scheduling/control-progress integration, worker-process physical waiting, broker cohorts and independent Node admission, other inference resource waits, foreign backend CPU teams, full API/production qualification and automatic default overload gates remain required. Defaults remain disabled.
